# Code Of Conduct

## Our Commitment

We want Solaris to be a high-signal project where people can discuss hard technical problems without posturing, hostility, or gatekeeping.

Participants are expected to:

- be respectful and direct
- criticize ideas without demeaning people
- prefer clarity over performative certainty
- help keep discussion grounded in evidence, code, and reproducible behavior

## Expected Behavior

- assume good intent while staying honest about problems
- welcome questions from people who are serious about learning or contributing
- keep technical disagreement constructive
- cite concrete behavior, tests, or docs when possible

## Unacceptable Behavior

- harassment or personal attacks
- discriminatory language
- doxxing or threats
- bad-faith disruption
- repeated low-signal trolling

## Scope

This applies in:

- issues
- pull requests
- discussions
- project chat spaces that are explicitly tied to Solaris

## Enforcement

Project maintainers may remove comments, close threads, or block participants whose behavior makes the project materially worse for others.

## Reporting

If something needs moderator attention, open a private channel through the repository contact path when available or raise it directly with the maintainers.

This document is intentionally short. The standard is simple: be serious, be decent, and make the project better.
